### Q24. CRUD操作

**回答**

- Create：タスクの追加
- Read：タスクの表示
- Update：タスクの内容変更

### Q25. データの制約

### Q30. ブランチとPull Request

- ブランチとは何ですか？
- Pull Request の目的は何ですか？
- なぜ全員が main に直接変更しないのですか？

**回答**

ブランチはmainの作業から分けて、更新などの変更作業を行なえる仕組み。
Pull Requestは、変更した内容を確認してもらう仕組み。
mainに直接変更してしまうと誤った内容やバグが含んでいる内容があった場合に、直接反映されて不具合が起きる可能性があるため。

### Q31. コミットメッセージの重要性

例：`feat: ログイン機能を追加` 良いコミットメッセージを書くことがなぜ重要ですか？

**回答**

どのような変更をしたのか他の人やあとから確認したときに分かりやすくするため。
