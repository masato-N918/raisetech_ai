# 非機能要件：Trello風タスク管理アプリ

> 中央ドキュメント：[要件定義書.md](要件定義書.md)

| 分類 | 項目 | 要件 |
|------|------|------|
| 性能 | 操作の反応 | カード追加・移動・検索などの操作は、体感で待たずに反映される（目安1秒以内） |
| 性能 | 画面の更新 | カードの追加・編集・チェック項目の操作後は、該当カードだけを更新し、画面全体を読み込み直さない |
| 性能 | 想定データ量 | 個人利用の範囲（目安：ボード1枚／カード〜100）で快適に動作する |
| 可用性 | 動作環境 | 自分のPC（ローカル）と AWS（EC2 1台 + RDS）で動作する。AWS は本人だけが使う前提で、必要なときだけ構築し、使わないときは削除する（構成は [インフラ設計書.md](インフラ設計書.md)） |
| 可用性 | 稼働時間・冗長化 | 常時稼働・冗長化（マルチ AZ、複数台構成）は対象外。サーバー 1 台・DB シングル AZ とする |
| 対応環境 | 対応ブラウザ | PCのモダンブラウザ最新版（Chrome / Edge / Firefox / Safari）。IE は対象外 |
| 対応環境 | 画面サイズ | PC画面幅を主対象。スマホ幅でもレイアウトが大きく崩れない程度には最低限対応する（D&D等の操作性はPC前提） |
| データ | 永続化 | リロードしても消えない。PostgreSQL に保存する（カードの並び順・並べ替え結果も含む） |
| データ | バックアップ | 必須としない（学習用途のため。将来拡張で検討）。AWS の RDS も自動バックアップは無効にしており、環境を削除すると DB のデータは消える |
| ユーザビリティ | 操作性 | マウスのD&Dで直感的に操作できる。主要操作はクリック数が少ない |
| ユーザビリティ | 誤操作防止 | カードの削除は確認のうえ実行する |
| 保守性 | コード | 学習目的として、機能ごとに整理された読みやすい構成とする |
| セキュリティ | 認証 | 1人利用前提のためログイン・権限管理は実装しない |
| セキュリティ | アクセス制限 | AWS 上では、画面・API（HTTP）と SSH を本人の IP からだけ許可する。DB（RDS）はインターネットに公開せず、アプリのサーバーからだけ接続できるようにする |
| セキュリティ | 通信の暗号化 | HTTP のみとし、HTTPS は対象外（本人の IP からしかアクセスできないため。将来拡張で検討） |
| セキュリティ | 秘密情報 | DB のパスワードなどは Git に含めない。AWS では SSM パラメータストアに暗号化して保存し、アプリの起動時に読み込む |
| 運用 | 費用 | 使うときだけ環境を構築し、使い終わったら削除して、費用を最小限に抑える（常時稼働した場合の目安は月 $35 程度） |
| 運用 | 構築・デプロイ | インフラは Terraform でコード化し、誰が何度作っても同じ環境になるようにする。デプロイはスクリプト 1 本で行えるようにする |
